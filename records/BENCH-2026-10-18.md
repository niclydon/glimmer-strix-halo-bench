# Glimmer benchmark — Oct 18, 2026

Target: Forge alias default-agent -> muse-glimmer-30b on Crucible (llama.cpp b11719, llama-swap v265, DFlash on, ctx 65536, parallel 2). All measurements foreground, run from Furnace through Forge unless marked direct. Bench script: ~/workspace/glimmer/bench.py. Condition note: qwen3.8-permissive-27b was co-resident (caller-loaded) during the run; embed mirror cold.

## Results

- Resolve + short chat: default-agent resolves to muse-glimmer-30b (model_resolution in response). Exact-answer test passed after think strip (final = BENCH_OK). 122 completion tokens in 5.0s wall: short replies pay ~120 reasoning tokens before the answer.
- Decode throughput: 20.8 tok/s predicted (llama.cpp timings, direct, 1000-token generation, 48.2s total). Through Forge streaming: 1000 tokens in 57.9s = ~17 tok/s wall. DFlash: 4,789 draft tokens proposed, 678 accepted into the 1,000 generated (per-token acceptance ~14%; net decode still 20.8 tok/s).
- Prefill: ~15,860-token prompt, 49.7s wall including a 60-token answer -> roughly 300-350 tok/s prefill (wall-derived estimate; timings object did not surface in that response). Cold large-context turns are slow; llama.cpp prompt caching mitigates across turns (one test showed 82 of 87 prompt tokens cached).
- Tool calls: 5/5 correct function with valid JSON args (get_weather, set_timer, search_contacts, create_note, convert_currency), 3.9-10.1s each, tool_choice auto.
- JSON output: 5/5 valid after stripping the <think> block; 0/5 raw (every response leads with reasoning). Caveat: 4 of the 5 tries were Forge response-cache replays (latency_ms = 1 in requests.db), so this is one real generation (11.0s) replayed identically at temperature 0. The think-prefix behavior was consistent across every Glimmer response today.
- Concurrency: 2 parallel 300-token requests both completed (19.1s and 36.0s). Aggregate throughput roughly conserved (~17 tok/s total): the 2 slots buy concurrency, not speed.
- Forge path quirk: one non-streamed 1000-token request returned 500 at ~17s; the identical streamed request returned 200, and the direct llama-swap request succeeded. Single observation, not a proven cap (long non-streamed requests passed earlier), but harnesses should stream.

## Harness implications

1. Strip think blocks in the harness (or run reasoning off) for any structured/JSON consumption.
2. Stream long generations through Forge.
3. Budget the reasoning tax on small calls (~5s and ~120 tokens for a trivial answer); Glimmer's reasoning level is system-prompt set (WS3 research), worth an A/B.
4. Big cold contexts cost ~3s per 1k tokens of prefill; keep agent contexts warm or compact.
